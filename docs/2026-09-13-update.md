# Queue, overlay and audio update

- Audio is explicitly resampled to 48 kHz without asynchronous speed compensation. Audio timestamps follow sample count. MPEG-TS senders mark their initial discontinuity when transitioning between videos and standby.
- Audio diagnostics report input codec, sample rate and channel count without credentials or media URLs.
- Combined sources accepts multiple playlist links and channel links/handles. Sync deduplicates videos by YouTube video ID and applies exclusion filters.
- The single optional Shuffle control randomizes videos and separates items longer than 70 minutes. Runtime selection enforces the rule even after failures and at loop boundaries. Unknown durations are conservatively treated as long. When a shorter item is unavailable, playback waits instead of breaking the rule.
- Downloads are serialized. Cache cleanup also runs on cache hits, retaining only the current and requested video. Existing byte limits remain in force, including temporary merge files; two very long videos can still require substantial space.
- Full titles wrap and shrink within the avatar height. Upload dates appear below them in white with a black outline, formatted `Sep.13.26` in UTC. Sync refreshes upload dates. The real frame preview uses the same title and date.
- The Overview YouTube viewer accepts broadcast links and displays YouTube's delayed viewer output.

Verification: real FFmpeg regression tests, 44.1/48 kHz tone frequency/duration/impulse checks, cache-hit cleanup, combined-source deduplication, overlay bounds/date format and 1080p60 encoding. These controlled audio checks do not establish the root cause of the user's reported audio issue. Sustained real broadcast listening and an 8-hour playback run remain unverified.

Earlier unsuccessful troubleshooting included restarting/reloading, verifying stream-key loading and executable availability, using public videos instead of unlisted items, testing videos under five minutes, and increasing cache capacity. Earlier download diagnosis identified an unresolved FFmpeg executable path passed to yt-dlp, which prevented merging; that was fixed before this update. Do not test unlisted videos.
